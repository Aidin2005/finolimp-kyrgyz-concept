# Инструмент сверки расчётов с субагентами (FinOlimp 2026 · Kyrgyz Concept)

Автоматизированный сквозной пайплайн аудита, сопоставления транзакций (Reconciliation Engine), поиска аномалий и машинного обучения (ML) для выявления финансовых расхождений между билетной системой ETM, актами 1С и ручным реестром продаж.

Оснащён **интуитивным веб-интерфейсом для бухгалтерии** и консольным скриптом для пакетной обработки.

---

## 🌐 Веб-интерфейс для бухгалтера (Без кода)

Бухгалтеру не нужно запускать команды или работать с кодом. Достаточно запустить веб-приложение:

```bash
python3 app.py
```
И открыть в любом браузере: **[https://finolimp-kyrgyz-concept.onrender.com]([http://localhost:5050](https://finolimp-kyrgyz-concept.onrender.com))**

### Возможности веб-интерфейса:
1. **Drag-and-Drop загрузка файлов:** просто перетащите три файла (`acts.csv`, `etm.csv`, `registry.csv`) в окно браузера, либо нажмите кнопку *«Использовать текущие выгрузки (янв–июл 2026)»*.
2. **Интерактивный дашборд:**
   * Ключевые показатели: сматчено операций, сумма дельты, суммы корректировок для ETM и 1С.
   * **Сводка по 100 субагентам:** мгновенный поиск по названию, фильтр по статусу сходимости.
   * **Детализация 5 652 расхождений:** фильтр по источникам (1С, Бот, Агент), поиск по билетам и операторам.
   * **Аномалии и антифрод:** двойные списания, повторные оплаты, выбросы сумм.
   * **ML-скоринг рисков:** предиктивный рейтинг субагентов по вероятности ошибок.
3. **Скачивание готового отчёта:** кнопка *«Скачать отчёт в Excel (.xlsx)»* для немедленного получения готового отчёта с оформлением и автофильтрами.

## 💻 Консольный запуск (CLI для жюри и автоматизации)

```bash

python3 -m pip install -r requirements.txt

# 2. Запуск пайплайна

# Для указания нестандартных путей:
python3 main.py --data_dir /путь/к/данным --output_dir /путь/к/выгрузке
```

## 🤖 Модель машинного обучения (ML Pipeline)

* **Алгоритм:** Градиентный бустинг **LightGBM** (бинарная классификация вероятности ошибки $P(\text{error})$ и мультиклассовая классификация источника ошибки).
* **Честная валидация (Temporal Hold-out):**
  * Train: Январь – Июнь 2026 (20 786 транзакций).
  * Test: Июль 2026 (4 451 транзакций).
  * Таргет-энкодинги вычислены строго на обучающей выборке (без data leakage).
* **Метрики качества на отложенной выборке (Июль 2026):**
  * **ROC-AUC:** `0.7047`
  * **PR-AUC:** `0.1802`
  * **Multiclass Accuracy:** `0.8913`
* **Топ-5 признаков (Feature Importance):**
  1. `abs_amount` — сумма транзакции в сомах
  2. `agent_err_rate` — исторический риск субагента
  3. `day` / `dayofweek` — календарная сезонность
  4. `air_err_rate` — авиакомпания
  5. `emp_err_rate` / `employee` — оператор, оформлявший заказ
